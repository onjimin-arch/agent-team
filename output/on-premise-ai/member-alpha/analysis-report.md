# 개요

**온프레미스 AI(On-Premise AI)** 는 대규모 언어 모델(LLM)·멀티모달 모델을 퍼블릭 클라우드가 아닌 기업 자체 데이터센터 혹은 코로케이션(IDC) 환경에서 학습·서빙하는 운영 방식을 의미한다. 2023~2024년에는 "GPT-4 API 를 쓰면 된다" 는 클라우드 우선 기조가 지배적이었으나, 2026년 현재는 세 가지 변수가 동시에 작동하면서 온프레미스 AI 가 재부상하고 있다.

1. **규제 압력 강화** — 2026년 1월 시행된 AI 기본법 시행령, 금융권 망분리 완화 대신 강화된 AI 감독규정, 의료 가명정보 2.0 가이드라인 등으로 민감 데이터의 클라우드 외부 유출 리스크가 정량화되기 시작했다.
2. **오픈소스 모델의 품질 수렴** — Llama 4, Qwen 3, DeepSeek V3 등 오픈웨이트 모델이 GPT-4 급 벤치마크를 달성하면서 "온프레미스 = 성능 하향" 공식이 깨졌다.
3. **TCO 역전 구간 확대** — 대규모 추론(월 10억 토큰 이상) 워크로드에서 온프레미스 3년 TCO 가 클라우드 API 대비 30~60% 저렴해지는 손익분기 구간이 명확해졌다(추정).

# 분석 결과

## A. 기업 도입 전략

### 왜 온프레미스인가?
- **데이터 주권(Data Sovereignty)**: 학습·추론 과정에서 프롬프트·응답이 외부로 유출되지 않음. 금융·의료·공공·국방에서는 법적 요구사항.
- **레이턴시**: 동일 네트워크 세그먼트 내 서빙으로 TTFT(Time-To-First-Token) 를 50~150ms 로 단축 가능(클라우드 API 는 300~800ms 대). 실시간 콜센터·자동화 워크플로우에서 결정적 요인.
- **규제 적합성**: 개인정보보호법 제28조의2(가명처리), 금융권 망분리, AI 기본법의 고영향 AI 의무(투명성·편향성 점검) 가 외부 모델 사용 시 대응 난이도를 증가시킴.
- **TCO**: 월 10억 토큰 이상 추론 시 클라우드 API(GPT-4o, Claude Sonnet 4.6) 대비 3년 기준 손익분기를 넘어서는 구간에서 유리(추정, E축 상세).

### 적합 기업·워크로드 프로파일
| 산업 | 적합도 | 대표 워크로드 |
|---|---|---|
| 금융(은행·증권·보험) | 매우 높음 | 내부 문서 RAG, 고객 상담 요약, 규제 보고서 자동화 |
| 의료(대형병원·제약) | 매우 높음 | EMR 요약, 임상시험 문헌 분석, 의료영상 멀티모달 |
| 공공·국방 | 매우 높음 | 정책 문서 분석, 민원 자동응답, 정보 분류 |
| 제조(자동차·반도체) | 높음 | 특허·논문 검색, 설비 로그 분석, 품질 불량 NLP |
| 통신·미디어 | 중간 | 고객 상담, 콘텐츠 추천 설명 생성 |
| 일반 SaaS·스타트업 | 낮음 | 대부분 클라우드 API 가 유리 (초기 트래픽 불확실) |

### 도입 단계별 로드맵 (대략 12~18개월)
1. **PoC (0~3개월)**: GPU 1~2대 환경에서 Llama 3.3 70B 혹은 Qwen 2.5 72B 를 vLLM 으로 서빙, 사내 문서 10~100 건 대상 RAG PoC.
2. **파일럿 (3~9개월)**: 1~2개 부서 한정 프로덕션 유사 환경. 로그·감사·모니터링 스택(Prometheus, Grafana, LangSmith 대체 오픈소스) 구축. SLO(P95 레이턴시, 가용성 99.5%) 정의.
3. **프로덕션 확장 (9~18개월)**: 멀티노드 클러스터, HA 구성, 모델 업데이트 파이프라인(LoRA 파인튜닝 포함), Red Team 가드레일 테스트, 감사 로그 SIEM 연동.

- **서버**: 8 GPU HGX 보드(H100/H200/B200) + Dual EPYC 9654 또는 Xeon 8592+ + 2 TB DDR5 + NVMe 30~60 TB (모델 가중치·KV 캐시용).
- **노드 간 네트워크**: InfiniBand NDR 400Gb/s 또는 RoCE v2 400GbE. 멀티노드 학습·파이프라인 병렬 추론(PP) 필수. 8노드 이상이면 Fat-Tree 토폴로지 권장.
- **스토리지**: 훈련 데이터용 병렬 파일시스템(WekaFS, DDN Lustre, VAST) 혹은 MinIO + NVMe-oF. 1 PB 급이 중견기업 기준.

### 전력·냉각
- H100 8 GPU 노드 = 약 10~12 kW, B200 8 GPU 노드 = 14~18 kW. 랙당 40~60 kW 밀도.
- 공냉 한계는 랙당 30~35 kW. 그 이상은 **액침냉각(immersion) 또는 DLC(Direct Liquid Cooling)** 필수. GB200 NVL72 는 100% 수냉.
- PUE 1.3 기준 연간 전력비: 10 kW 노드 = 약 1,500만원/년 (한국 산업용 전력 약 170원/kWh 추정).

- **Llama 계열**: 월 활성 사용자(MAU) 7억 초과 기업은 Meta 별도 계약 필요. 또한 Llama 로 학습된 파생 모델 이름에 "Llama" 포함 권고.

### 운영 난이도 (추론 프레임워크)
- **vLLM**: 가장 널리 사용. PagedAttention 으로 처리량 우수. 70B 모델 서빙 시 H100 2장(TP=2) 혹은 4장(FP16).
- **TensorRT-LLM**: NVIDIA 최적화, 최고 throughput 이지만 빌드 복잡도 높음. 엔진 재빌드 필요.
- **SGLang**: RadixAttention, 구조화된 출력(JSON) 강점. Agent 워크로드에 적합.
- **양자화**: AWQ / GPTQ 4-bit 로 VRAM 50~60% 절감, 성능 손실 2~5% 수준(추정).

## D. 보안·컴플라이언스

### 국내 적용 규제 목록 (2026년 4월 기준)
1. **개인정보보호법** — 개인정보 처리 최소화·목적 구속 원칙. 학습데이터·프롬프트에 개인정보 포함 시 가명처리 또는 동의 필요.
2. **AI 기본법(인공지능 발전과 신뢰 기반 조성 등에 관한 기본법) 2026.1월 시행령** — 고영향 AI(의료·금융·채용·공공) 사업자의 안전성·신뢰성 확보 의무, 영향평가·문서화·투명성 조항. (정확한 조문·시행 일정은 gamma 팩트체커 검증 권고)
3. **금융권 망분리 / 전자금융감독규정** — 내부망 AI 서비스는 외부 통신 차단 구조 필수. 생성형 AI 망분리 예외(일부 비업무망 활용) 가이드라인 개정 중 (추정).
4. **의료 가명처리 가이드라인 2.0** — EMR 기반 학습·추론 시 결합키 관리·재식별 위험평가 의무.
5. **CSAP(Cloud Security Assurance Program)** — 공공기관 납품 시 해당. 온프레미스면 직접 적용 아니지만, 하이브리드 구성 시 부분 적용.
6. **ISMS-P / ISO 27001·27701** — 국내외 정보보호 인증. AI 시스템 포함 통제항목 추가 권고.

### 데이터 주권 / 국외이전
- 개인정보 국외이전은 원칙 금지(동의·계약·인증 예외). 온프레미스는 물리적 국내 보관으로 대부분 해소되지만, **모델 가중치 자체가 국외 데이터 학습 결과**인 경우 별도 검토 필요(특히 의료·국방).

### 모델 가드레일
- **프롬프트 인젝션 방어**: 입력 사전검사(정규식 + 분류기), 시스템 프롬프트 보호(명시적 구분자), 출력 후처리.
- **PII 필터**: 입·출력 양방향. Presidio 오픈소스 혹은 자체 개발. 주민번호·카드번호·전화번호 정규식 + NER.
- **출력 모니터링**: 유해·편향·허위 응답 감지. LlamaGuard 3 / ShieldGemma 등 온프레미스 가능 가드레일 모델 병행.

### 감사·로깅
- 모든 프롬프트·응답 로깅(단, PII 마스킹). 최소 1년 보관 권고.
- 접근 로그(IAM·SSO 연동), 모델 버전 추적, 파인튜닝 데이터 리니지.
- SIEM 연동으로 이상 탐지 (비정상 토큰 소비, 특정 사용자의 민감 정보 요청 패턴).

## E. 비용 대비 효과 TCO

### 시나리오별 3년 TCO 추정

#### 시나리오 1: 중소기업 — GPU 서버 1~2대, 연 1~5억 토큰
- **CapEx**: H100 4 GPU 서버 1대(약 1.5억원) + 네트워크·스토리지(0.5억원) = **약 2억원**
- **OpEx (3년)**: 전력 약 800만원/년 × 3 + 인력(MLOps 0.5 FTE, 연 6,000만원) × 3 + 유지보수 10% = **약 2.4억원**
- **3년 총 TCO**: **약 4.4억원 (추정)**
- 비고: 연 5억 토큰 × 3년 = 15억 토큰. 클라우드 GPT-4o(입출력 평균 $5/M 토큰 추정) 환산 시 약 1억원 — **오히려 클라우드가 저렴**. 중소기업은 클라우드 API 권장.

#### 시나리오 2: 중견기업 — 8 GPU 노드 × 2, 연 50~200억 토큰
- **CapEx**: H100 8 GPU 노드 2대(약 6억원) + InfiniBand·스토리지·구축(2억원) = **약 8억원**
- **OpEx (3년)**: 전력 약 4,000만원/년 × 3 + 인력(MLOps 2 FTE, 연 2.4억원) × 3 + 유지보수·라이선스 = **약 9억원**
- **3년 총 TCO**: **약 17억원 (추정)**
- 비고: 연 200억 토큰 × 3년 = 600억 토큰. 클라우드 API 환산 약 40~60억원 — **온프레미스 50~70% 절감 가능**. 손익분기 대략 월 30~40억 토큰 수준(추정).

#### 시나리오 3: 대기업 — 64 GPU 클러스터 이상, 연 1조+ 토큰
- **CapEx**: H200/B200 64 GPU(8노드) 약 40~50억원 + 네트워크·냉각·전력증설 10~20억원 = **약 50~70억원**
- **OpEx (3년)**: 전력 약 3~4억원/년 × 3 + 인력(AI 플랫폼팀 10 FTE, 연 12억원) × 3 + 유지보수 = **약 45~50억원**
- **3년 총 TCO**: **약 100억~120억원 (추정)**
- 비고: 연 1조 토큰 × 3년 = 3조 토큰. 클라우드 API 환산 약 1,500~2,000억원 — **온프레미스 90% 이상 절감 가능**. 단, 파인튜닝·커스텀 모델 학습 비용 별도.
