## 시각자료 개요

본 문서는 member-alpha 의 분석 결과와 member-gamma 의 팩트체크 수정 권고를 반영하여 도심물류 OS 의 구조·프로세스·경쟁 지형·핵심 수치를 4개 Mermaid 다이어그램과 4개 테이블로 시각화한 것이다. gamma 가 "불일치" 로 플래그한 수치(Onfleet 2022-06 / 23M USD, 바로고 2021년 909억원, Amazon Prime Air BVLOS 2024년 5~6월, Getir-Gorillas 2022년 12월)는 gamma 의 수정안을 우선 반영했으며, 그 외 "출처 불명" 또는 "부분 일치" 는 각주로 표시한다.

수록 목록:

- 다이어그램 1 - 도심물류 OS 기능 모듈 구조도 (flowchart LR): 주문 수집부터 정산·알림까지의 모듈 스택 시각화
- 다이어그램 2 - 주문부터 배송 완료까지 메시지 흐름 (sequenceDiagram): 고객·커머스·OS·기사·창고·알림 채널 간 상호작용
- 다이어그램 3 - 플레이어 포지셔닝 4분면 (quadrantChart): 국내 대 해외 축과 SaaS 대 수직통합 축 교차
- 다이어그램 4 - 2023~2025 주요 M&A / 자본 이벤트 타임라인 (timeline): 구조조정과 전략적 인수의 순서
- 테이블 1 - 국내 주요 플레이어 비교
- 테이블 2 - 해외 주요 플레이어 비교
- 테이블 3 - 시장 규모와 성장률 요약
- 테이블 4 - 2023~2025 주요 M&A 와 자본 이벤트

### 다이어그램 1. 도심물류 OS 기능 모듈 구조도

캡션: 주문 수집부터 라우팅·디스패치·라이더 앱·완료·정산·고객 알림까지 도심물류 OS 가 종단간으로 통합하는 9개 기능 모듈의 연결 구조.

```mermaid
flowchart LR
    subgraph INGEST[주문 채널 Order Ingestion]
        A1[Shopify / Cafe24 / 스마트스토어]

        A3[SLA 약속시간 파서]
    end

    subgraph CORE[OS 코어]
        B1[라우팅 엔진<br/>VRP / VRPTW / PDP]
        B2[디스패치 오케스트레이션<br/>매칭 / 번들링 / ETA]
        B3[관리 콘솔<br/>SLA / FADR / CPD]
    end

    subgraph EXEC[실행 레이어]
        C1[라이더 / 드라이버 앱]

    subgraph CLOSE[완료와 정산]
        D1[실시간 트래킹과 고객 알림<br/>SMS / 카톡 / ETA 페이지]
        D2[정산과 세금<br/>수수료 / 원천징수 / 정산서]
        D3[개방형 API 와 화이트라벨<br/>Uber Direct / DoorDash Drive]

    INGEST --> B1
```

### 다이어그램 2. 주문에서 배송 완료까지 메시지 흐름

캡션: 단일 주문 한 건이 고객 - 커머스 - OS - 기사 - 창고 - 고객 알림 채널을 왕복하며 생성되는 주요 이벤트 메시지의 시간 순서.

```mermaid
sequenceDiagram
    participant C as 고객
    participant S as 커머스 / POS
    participant O as 도심물류 OS
    participant W as 창고 / MFC
    participant R as 기사 / 라이더
    participant N as 알림 채널

    C->>S: 주문 생성과 결제
    S->>O: 주문 전송 (API, SLA 포함)
    O->>O: 라우팅 엔진 (VRPTW) 최적화
    O->>R: 배차 오퍼 (auto-assign 또는 경매)
    R-->>O: 수락
    O->>W: 픽업 지시
    W->>R: 상품 픽업과 송장 스캔
    R->>O: 픽업 완료 상태
    O->>N: 고객에게 ETA 링크 푸시
    N->>C: 실시간 ETA 와 GPS 트래킹
    R->>C: 전달 시도 (사진 / PIN / 서명)
    R->>O: 전달 완료 증빙 업로드
    O->>S: 배송 완료 콜백
    O->>R: 수수료 자동 계산과 정산서 반영
    O->>N: 고객 만족도 조사 발송
```
