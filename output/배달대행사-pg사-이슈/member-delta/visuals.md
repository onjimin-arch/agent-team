# 시각자료 개요

이 문서는 배달대행사 PG 이슈를 `거래 흐름`, `리스크 확대 경로`, `핵심 수치`로 빠르게 파악할 수 있도록 구성했다. 수치는 모두 upstream 산출물에 이미 등장한 값만 사용했다.

# Mermaid 다이어그램

배달대행사와 PG사의 기본 거래/정산 구조

```mermaid
flowchart LR
    C[소비자] -->|주문 및 결제| PG[PG사]
    PG -->|승인/결제수단 처리| Card[카드사·간편결제]
    PG -->|정산금 지급| Agency[배달대행사]
    Agency -->|배달대행료/정산| Store[가맹점주]
    Agency -->|수수료/보수 지급| Rider[라이더·기사]
    Agency -->|보증금·충전금 관리| Wallet[예치금 계정]
    PG -->|에스크로/지급대행/가상계좌| Ops[부가 금융기능]
```

규제 강화와 운영 미비가 결합될 때의 리스크 확대 경로

```mermaid
flowchart TD
    A[대리점별 상이한 계약] --> B[정산 대상 식별 불명확]
    B --> C[KYC·가맹점 심사 지연]
    C --> D[정산 지연 또는 보류]
    D --> E[가맹점·라이더 불만]
    E --> F[이탈 및 평판 훼손]
    A --> G[보증금·운영자금 혼재]
    G --> H[환불 우선순위 혼선]
    H --> F
    I[3.2~3.5% 수수료 + D+3~D+7 정산] --> J[현금흐름 압박]
    J --> F
    K[정산자금 외부관리·고객확인 강화] --> C
    K --> J
```
