본 문서는 `member-alpha/analysis-report.md`의 분석 결과를 Mermaid 다이어그램과 Markdown 테이블로 시각화한 자료이다. 포함된 시각자료:

2. **품목별 폐기율 비교 다이어그램** (Mermaid xychart-beta / bar chart spec)

## Mermaid 다이어그램

### 다이어그램 1: 농산물 폐기 원인 구조 흐름도

농산물 폐기가 발생하는 구조적 원인과 경로를 시각화한 흐름도.

```mermaid
flowchart TD
    A[농산물 생산] --> B{품질 선별}
    B -- 규격 충족 --> C[정상 유통 채널]
    B -- 규격 미달·등외품 --> D[산지 폐기 / 저가 처리]
    
    C --> E{유통 단계}
    E -- 정상 판매 --> F[소매·소비자]
    E -- 과잉 재고 --> G[도매시장 경매 미낙찰]
    G --> H[폐기 or 사료 처리]
    
    F --> I{소비자 단계}
    I -- 소비 완료 --> J[완료]
    I -- 미소비 잔류 --> K[가정 내 음식물 폐기]
    
    D --> L[폐기율 증가 요인]
    H --> L
    K --> L
    
    L --> M[수급 예측 실패]
    L --> N[콜드체인 부족]
    L --> O[가공 인프라 미흡]
    L --> P[가격 지지 정책 한계]
```

### 다이어그램 2: 가격 폭락 → 산지 폐기 악순환 사이클

전남 채소류에서 반복되는 과잉 생산-폐기-가격 폭락 사이클 도식.

```mermaid
flowchart LR
    A["전년도 가격 급등\n(예: 배추·양파 고가)"] --> B["농가 재배 면적 확대\n(다음 시즌)"]
    B --> C["과잉 생산 발생\n(수요 대비 공급 초과)"]
    C --> D["도매가 폭락\n(운임도 못 건지는 가격)"]
    D --> E["산지 폐기 결정\n(갈아엎기·출하 포기)"]
    E --> F["폐기 보상금 지급\n(농협·지자체)"]
    F --> G["가격 일시 회복"]
    G --> A
    
    style A fill:#ffcccc
    style C fill:#ff9999
    style E fill:#ff6666
    style G fill:#ccffcc
```

### 다이어그램 3: 전남 수산물 폐기 원인 구조

```mermaid
flowchart TD
    A[수산물 생산\n어획·양식] --> B{품질·규격 검사}
    B -- 합격 --> C[국내 유통]
    B -- 수출 검역 불합격 --> D[반송·폐기]
    B -- 규격 미달 --> E[저가 가공 원료]
    
    C --> F{유통·저장}
    F -- 냉장·냉동 처리 --> G[정상 판매]
    F -- 저온 유통 한계 --> H[선도 저하 → 폐기]
    
    I[기후 재해] --> J[이상 고수온·적조]
    J --> K[양식장 집단 폐사]
    K --> H
    
    L[양식장 밀도 과잉] --> K
    
    H --> M[수산물 폐기율 증가]
    D --> M
```
