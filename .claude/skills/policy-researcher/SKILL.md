# Policy Researcher Skill

## Purpose
member-theta가 정책·입법·규제 동향을 탐색·분석·영향도 판정하는 데 필요한 검색 레퍼런스,
영향도 rubric, 출처 신뢰도 기준을 제공한다.

## When to Use
member-theta가 Execution Rules의 탐색 절차(Step 1–5)를 수행할 때 호출한다.

## Search Reference

| 대상 | 검색 방법 |
|------|----------|
| 국회 입법 예고·의안 현황 | 국회 의안정보시스템(likms.assembly.go.kr) 검색, WebSearch로 `"의안명" site:likms.assembly.go.kr` 또는 `"의안명" 국회 의안정보시스템` |
| 현행 법령·개정 이력 | 국가법령정보센터(law.go.kr) 검색, WebSearch로 `"법령명" site:law.go.kr` |
| 정부 관보(고시·공고) | 관보(gwanbo.go.kr) 검색 |
| 부처 보도자료·정책 브리핑 | 소관 부처 공식 보도자료실 검색 (예: 국토교통부, 공정거래위원회, 고용노동부 등 — Assignment에서 지정된 부처 우선) |
| 업계 동향·2차 보도 | 일반 뉴스 검색으로 보완하되, 반드시 1차 출처(법령/의안/부처 발표)로 교차 확인 |

**원칙**: 원문(법령 조항, 의안 원문, 부처 보도자료)을 우선 인용하고, 언론 해석 기사만으로 사실관계를 단정하지 않는다.

## 영향도 분석 3단계 Rubric

| 등급 | 판정 기준 | 처리 |
|------|----------|------|
| 직접영향 | 당사 사업 모델·매출·비용 구조·규제 준수 의무에 즉각적·구체적 영향 | 대응 방안 수립 필수, Team Lead 즉시 보고 |
| 간접영향 | 업계 전반에 영향, 당사에는 간접적이거나 시행까지 시간 여유 있음 | 모니터링 지속 + 대응 방안 초안 |
| 모니터링만 | 발의·예고 초기 단계로 영향 범위 불명확 | 정기 추적 대상으로만 기록, 대응 방안 불필요 |

등급 판정 근거는 반드시 "어느 조항이 무엇을 어떻게 바꾸는지"를 구체적으로 적어야 한다 — "영향이 있을 수 있음" 같은 모호한 서술은 금지.

## 출처 신뢰도 기준

| 등급 | 예시 | 처리 |
|------|------|------|
| 1차 출처 | 법령 원문, 의안 원문, 관보, 부처 공식 보도자료 | 그대로 인용 가능 |
| 2차 출처 | 통신사·주요 일간지 팩트 보도 | 1차 출처 확인 전까지 "보도 기준"으로 표시 |
| 미확인 | 커뮤니티/블로그/출처 불명 SNS | 인용 금지, 필요 시 "확인 필요" 항목으로만 기록 |

## Escalation Rule
법령 해석이 모호하거나(예: 소급 적용 여부, 시행령 미제정) 상충되는 보도가 있는 경우, 임의로
단정하지 말고 리포트에 "확인 필요"로 표시한 뒤 Team Lead에 보고한다.
