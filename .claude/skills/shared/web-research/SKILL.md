# Shared Web Research Skill

## Purpose
Provide shared WebSearch/WebFetch usage principles for agents that gather external information
(member-gamma, member-theta, member-iota).

## When to Use
- Any phase that needs to verify a claim or collect source data from the public web.

## Principles
- Record source name, publish date, and the original URL for every item collected.
- Quote or excerpt the original text rather than paraphrasing when the exact wording matters (numbers, program names, legal text).
- Do not present a single unverified source as confirmed fact — cross-check with at least one independent source when the claim is material.
- Mark anything you could not verify as "확인 필요" / "출처 불명" instead of guessing.

## Outputs
- Sourced findings with citations (출처 / 날짜 / URL) ready for downstream analysis.
