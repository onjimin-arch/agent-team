# Crisis Comms Skill

## Purpose
member-iota가 언론·SNS를 모니터링하고 위기 단계를 판정하는 데 필요한 검색 패턴, 판정 매트릭스,
골든아워 체크리스트, 톤앤매너 가이드를 제공한다.

## When to Use
member-iota가 Execution Rules의 모니터링 절차(Step 1–5)를 수행할 때 호출한다.

## Monitoring Search Reference

| 대상 | 검색 방법 |
|------|----------|
| 뉴스 보도 | WebSearch로 `"{키워드}" 뉴스`, `"{키워드}" 기사` — 최신순으로 우선 확인 |
| SNS 언급 | WebSearch로 `"{키워드}" 트위터/X`, `"{키워드}" 커뮤니티 반응` 등 플랫폼별 키워드 조합 |
| 경쟁사/업계 비교 이슈 | 동일 이슈에 대한 업계 타사 대응 사례를 함께 검색해 대응 수위 참고 자료로 활용 |

각 항목은 출처(매체/채널명)·게시일·원문 URL·논조(긍정/중립/부정)를 반드시 함께 기록한다.

## 위기 단계 판정 매트릭스

| 단계 | 판정 기준 |
|------|----------|
| 관심 | 부정적 언급이 소수이고 특정 커뮤니티에 국한, 확산 조짐 없음 |
| 주의 | 부정적 언급이 늘고 있고 일부 매체가 인용하기 시작함 |
| 경계 | 주요 매체가 직접 보도하고 있고 SNS 상 확산이 진행 중 |
| 심각 | 다수 매체·SNS에서 광범위하게 확산되고 여론이 뚜렷하게 악화됨 |

판정은 반드시 근거(언급 건수 추이, 보도한 매체 규모, 확산 속도)를 함께 제시한다 — 감으로 단정하지 않는다.

## 골든아워 체크리스트 (경계/심각 단계 전용)

| 시한 | 목표 |
|------|------|
| 1시간 이내 | 초기 모니터링 완료, 사실관계 초벌 정리(무엇이 왜 발생했는지) |
| 3시간 이내 | 1차 입장(사과/해명/유보 중 대응 방향) 정리 |
| 24시간 이내 | 공식 대응문서(beta 작성) 배포 목표 |

## 톤앤매너 가이드
- 사실관계가 확인되지 않은 상태에서 "사과"와 "해명"을 혼동해 제안하지 않는다 — 사실관계 확인 전에는 "유보/모니터링 중" 입장을 권고한다.
- 법적 책임이 걸린 사안(리콜, 소송, 인명 피해 등)은 반드시 리포트에 "법무 검토 필요" 문구를 명시한다.
- 대응 권고는 회사 입장을 방어하는 데만 치우치지 않고, 사실관계에 기반한 균형 잡힌 톤을 유지하도록 권고한다.
